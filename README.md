# torii-veldrid

[![dev chat](https://discordapp.com/api/guilds/188630481301012481/widget.png?style=shield)](https://discord.gg/zeuKQquCSE)

Veldrid is a cross-platform, graphics API-agnostic rendering and compute library for .NET. It provides a powerful, unified interface to a system's GPU and includes features designed for high-performance 2D and 3D graphics.

This repository is Torii's fork of [ppy/veldrid](https://github.com/ppy/veldrid) (which diverged from the upstream [Veldrid](https://github.com/veldrid/veldrid) project in April 2024). It is maintained to provide graphics backends (Vulkan, Metal, Direct3D 11, OpenGL) and platform-specific rendering enhancements for [Torii Framework](https://github.com/ShikkesoraSIM/torii-framework) and the [Torii client](https://github.com/ShikkesoraSIM/torii-osu).

## Community & Discussions

For discussions, graphics backend bug reports, and performance testing, please visit the [Torii Discord](https://discord.gg/zeuKQquCSE) or open an issue on [GitHub Issues](https://github.com/ShikkesoraSIM/torii-veldrid/issues).
